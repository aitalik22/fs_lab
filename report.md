Изучить устройство файловой системы Linux и научиться работать с файлами, ссылками, правами доступа и монтированием.

## Задание 1. Подготовка рабочего места

Создан рабочий каталог fs_lab, инициализирован репозиторий Git, создана ветка main и выполнен первый коммит.

## Задание 2. Исследование файловой системы

### Гипотеза

1. Корневая файловая система необязательно находится на /dev/sda1. Она может располагаться на другом устройстве.
2. В Linux может быть несколько одновременно смонтированных файловых систем.
3. Каталог /proc не является обычным дисковым каталогом, поскольку содержит виртуальную информацию о процессах и ядре операционной системы.

### Эксперимент

Для исследования файловой системы были выполнены команды:

- `ls /` — просмотр корневого каталога.
- `lsblk -f` — исследование блочных устройств.
- `df -hT -x squashfs` — проверка свободного пространства.
- `findmnt /` — определение источника корневой файловой системы.
- `findmnt /proc` — исследование виртуальной файловой системы proc.
- `findmnt /sys` — исследование файловой системы sysfs.

Результаты исследования дисков сохранены в файл `disks.txt`.

### Наблюдение

В ходе исследования были получены следующие результаты:

- Корневое устройство: /dev/sdd.
- Тип файловой системы: ext4.
- Точка монтирования: /.
- Общий объём: 1007 ГиБ.
- Занятое пространство: 2,6 ГиБ.
- Доступное пространство: 954 ГиБ.
- Использование пространства по данным df: 1%.

Также обнаружены файловые системы tmpfs, overlay, 9p и область подкачки swap.

### Вывод

В результате исследования установлено, что корневая файловая система Ubuntu расположена на устройстве /dev/sdd и имеет тип ext4. Внутри виртуальной файловой системы доступно 954 ГиБ, поэтому нехватки места по её показателям не наблюдается.

Linux позволяет одновременно использовать несколько файловых систем. Каталог /proc не является обычным дисковым каталогом, так как предоставляет информацию о процессах и ядре операционной системы.

Первоначальная гипотеза подтвердилась.
